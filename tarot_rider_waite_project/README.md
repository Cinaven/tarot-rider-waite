# El Loco · Tarot Rider-Waite-Smith

## Ver una vista previa
Abre `preview.html` en tu navegador. Necesita conexión a internet porque las imágenes de referencia se sirven desde Wikimedia Commons.

## Ejecutar la aplicación completa
1. Instala Node.js (versión LTS).
2. Abre una terminal dentro de esta carpeta.
3. Ejecuta `npm install`.
4. Ejecuta `npm run dev`.
5. Abre la dirección local que indique Vite (normalmente http://localhost:5173).

## Cambios realizados
- Se sustituyeron las imágenes de El Diablo, La Torre, La Estrella, Los Enamorados y El Mundo por ilustraciones Rider-Waite-Smith históricas del mismo mazo Roses & Lilies (1909).
- Se corrigió la miniatura de La Torre, que antes reutilizaba la imagen de El Loco.
- Se añadió la ilustración de La Torre a su ficha sin modificar las interpretaciones existentes.
- El resto de textos y contenidos de estudio se conservaron.
